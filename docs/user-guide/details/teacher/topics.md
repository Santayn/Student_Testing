# Преподаватель: темы

## 1. Открытие тем

1. Откройте раздел тем.
2. Выберите предмет, если контекст ещё не задан.
3. Дождитесь загрузки списка.

## 2. Создание темы

1. Нажмите действие создания темы.
2. Укажите порядковый номер.
3. Введите название.
4. При необходимости добавьте описание.
5. Сохраните.

Если порядок темы конфликтует с существующей записью, исправьте номер и повторите сохранение.

## 3. Редактирование

Откройте нужную тему, измените доступные поля и сохраните изменения.

## 4. Удаление

Используйте действие удаления у выбранной темы и подтвердите операцию, если интерфейс запрашивает подтверждение. Связанные данные могут ограничивать возможность удаления.

## 5. Поиск и сортировка

Используйте доступные элементы поиска и сортировки, когда список тем становится большим.
