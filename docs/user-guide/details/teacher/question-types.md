# Преподаватель: типы вопросов

## 1. Один правильный вариант

1. Создайте вопрос типа «один вариант».
2. Сохраните основной текст вопроса.
3. Добавьте варианты ответов.
4. Для каждого варианта задайте текст и порядок.
5. Отметьте один вариант как правильный.
6. Сохраните изменения.

## 2. Несколько правильных вариантов

1. Создайте вопрос соответствующего типа.
2. Добавьте варианты.
3. Отметьте все правильные варианты.
4. Проверьте, что правильных вариантов действительно несколько, если это требуется содержанием вопроса.
5. Сохраните.

## 3. Сопоставление

1. Создайте вопрос типа сопоставления.
2. Добавьте пары элементов.
3. Для каждой пары задайте левую и правую части.
4. Сохраните структуру.

Перед использованием в тесте проверьте, что пары заполнены полностью и не содержат случайных дублей.

## 4. Текстовый ответ

1. Создайте текстовый вопрос.
2. Введите формулировку.
3. Укажите ожидаемый правильный текстовый ответ.
4. Сохраните.

Учитывайте, что автоматическая проверка текстового ответа зависит от серверной логики сопоставления текста.
