# Преподаватель: банк вопросов

## 1. Выбор контекста

1. Откройте раздел банка вопросов.
2. Выберите предмет.
3. Выберите тему.
4. Дождитесь загрузки вопросов этой темы.

## 2. Работа со списком

В списке можно использовать поиск, сортировку и фильтры по доступным признакам, включая тип и активность вопроса.

## 3. Создание вопроса

1. Нажмите создание вопроса.
2. Введите текст.
3. Выберите тип вопроса.
4. Укажите количество баллов.
5. При необходимости задайте порядковый номер и состояние активности.
6. Сохраните вопрос.
7. Для типов с дополнительной структурой настройте варианты ответов или пары соответствия.

Подробности по каждому типу приведены в [отдельном разделе](./question-types.md).

## 4. Редактирование вопроса

Откройте существующий вопрос, измените доступные данные и сохраните изменения. Если изменяется тип вопроса, проверьте связанную структуру ответов.

## 5. Скрытие вместо удаления

Для обычной работы используется переключение активности вопроса. Скрытый вопрос остаётся в системе, но исключается из обычного использования в активном банке. При необходимости его можно снова активировать.

Это штатный сценарий вместо удаления вопроса через пользовательский интерфейс.
