# Преподаватель: лекции

## 1. Открытие

1. Перейдите в раздел лекций.
2. Выберите предмет.
3. Дождитесь загрузки списка.

## 2. Создание лекции

1. Нажмите создание лекции.
2. Введите название.
3. Добавьте описание.
4. Настройте доступную публикацию для студентов.
5. При необходимости выберите связанные тесты.
6. Сохраните.

## 3. Редактирование

Откройте существующую лекцию, измените доступные поля, связи с тестами или состояние публикации и сохраните.

## 4. Удаление

Используйте действие удаления у нужной лекции. Если интерфейс запрашивает подтверждение, проверьте выбранную запись перед окончательным действием.

## 5. Поиск, фильтры и сортировка

Для списка лекций доступны механизмы поиска/сортировки и фильтры, в том числе по публикации и наличию связанных тестов.

## 6. Материалы

Работа с файлами лекции описана отдельно: [материалы лекции](./lecture-materials.md).
