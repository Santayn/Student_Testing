# Преподаватель: импорт вопросов из Word

## 1. Подготовка

Импорт выполняется из файла формата `.docx` в выбранную тему. Перед импортом убедитесь, что нужный предмет и тема уже существуют.

## 2. Импорт

1. Откройте банк вопросов.
2. Выберите предмет и тему.
3. Откройте действие импорта Word.
4. Выберите файл `.docx`.
5. Запустите импорт.
6. Дождитесь итогового сообщения.

После успешной обработки интерфейс сообщает количество импортированных вопросов и связанных вариантов, если такие данные были созданы.

## 3. После импорта

Вернитесь к списку вопросов выбранной темы и проверьте созданные записи. Особое внимание уделите типам вопросов, правильным ответам и структуре вариантов.

Если импорт завершился ошибкой, проверьте формат файла и его соответствие ожидаемой структуре импорта.
