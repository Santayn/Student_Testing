# Преподаватель: версии курса

## 1. Создание версии

1. Откройте нужный шаблон курса.
2. Перейдите к версиям.
3. Нажмите создание новой версии.
4. Укажите номер версии.
5. Введите название.
6. Добавьте описание и описание изменений.
7. При необходимости включите немедленную публикацию.
8. Сохраните.

## 2. Изменение версии

Откройте существующую версию, измените доступные текстовые данные и сохраните.

## 3. Публикация

Версию можно опубликовать либо снять с публикации через доступные действия интерфейса.

## 4. Лекции версии

Из версии курса можно перейти к связанным лекциям и работать с учебным содержимым соответствующего варианта курса.

## 5. Ограничение

Отдельной пользовательской операции удаления версии курса в текущем интерфейсе нет. Не следует искать её как обязательную часть сценария.
