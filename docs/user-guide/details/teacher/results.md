# Преподаватель: результаты студентов

## 1. Открытие

Перейдите в раздел результатов в режиме преподавателя.

## 2. Выбор контекста

Фильтры формируют последовательность:

```text
Предмет → Лекция → Тест → Группа → Студент
```

Необязательно всегда доходить до конкретного студента: часть результатов может просматриваться на более широком уровне.

## 3. Просмотр

После выбора нужного контекста доступны сведения о попытках, баллах, процентах и другие данные результата. При наличии интерфейса детализации можно открыть отдельную попытку и просмотреть её ответы.

## 4. Если данных нет

Проверьте выбранный предмет, лекцию, тест и группу. Результат появится только для фактически завершённых попыток, доступных преподавателю в его учебном контексте.
