# Преподаватель: назначенные предметы

## 1. Открытие предметов

1. Переключитесь в рабочий режим преподавателя.
2. Откройте раздел предметов.
3. Выберите предмет, с которым хотите работать.

Преподаватель видит не весь справочник предметов системы, а доступный ему учебный контекст.

## 2. Если предмет отсутствует

Сам преподаватель не назначает себе предмет. Если нужного предмета нет, администратор должен проверить назначение преподавателя и учебную нагрузку.

От выбора предмета зависят темы, вопросы, лекции, тесты и другие учебные сущности, поэтому перед дальнейшей работой всегда проверяйте активный предмет.
