# Преподаватель: создание теста

Создание теста выполняется последовательным мастером из четырёх этапов.

## 1. Шаг «Контекст»

1. Откройте создание теста.
2. Выберите предмет.
3. Выберите одну или несколько доступных групп, если интерфейс позволяет соответствующий выбор.
4. Выберите тему.
5. Перейдите дальше.

Доступные группы зависят от учебной нагрузки преподавателя. Если группы нет в списке, сначала требуется административная настройка назначения.

## 2. Шаг «Параметры»

1. Введите название теста.
2. Добавьте описание, если оно требуется.
3. Перейдите к настройке вопросов.

## 3. Шаг «Состав вопросов»

Укажите:

- общее количество вопросов;
- количество разрешённых попыток;
- число текстовых вопросов;
- число вопросов с одним вариантом;
- число вопросов с несколькими вариантами;
- число вопросов на сопоставление.

Если сумма явно заданных типов меньше общего количества, оставшаяся часть может подбираться автоматически.

Интерфейс проверяет, достаточно ли активных вопросов нужных типов в выбранной теме. При нехватке вопросов вернитесь в банк вопросов и дополните его либо уменьшите требуемое количество.

## 4. Шаг «Доступность»

Настройте состояние теста и, при необходимости, период доступа:

- черновик;
- активно;
- закрыто;
- приостановлено;
- дата/время начала;
- дата/время окончания.

## 5. Создание и назначения

После подтверждения система создаёт тест и связывает его с выбранным учебным контекстом. Если назначение группам не удалось, интерфейс обрабатывает ошибку и не должен оставлять пользователя с незаметно частично завершённым сценарием.

## 6. Перед публикацией

Проверьте:

- правильность темы;
- наличие достаточного числа активных вопросов;
- число попыток;
- период доступности;
- выбранные группы;
- статус теста.

В текущем интерфейсе основной акцент сделан на создании теста. Отдельный полноценный раздел общего CRUD всех тестов ограничен по сравнению с редакторами тем и лекций.
