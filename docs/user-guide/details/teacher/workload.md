# Преподаватель: учебная нагрузка

Раздел предназначен преимущественно для просмотра назначений, подготовленных администратором.

## 1. Открытие

Перейдите в раздел **«Моя нагрузка»**.

## 2. Доступные сведения

Для назначений могут отображаться:

- предмет;
- группа;
- тип нагрузки;
- часы в неделю;
- учебный период;
- статус;
- примечания.

Также интерфейс может показывать сводные показатели: количество предметов, групп и суммарные часы.

## 3. Фильтры

Используйте доступные фильтры для сокращения списка назначений.

## 4. Важное ограничение

Преподаватель не назначает себе учебную нагрузку самостоятельно. Если данные отсутствуют или неверны, их должен изменить администратор.
