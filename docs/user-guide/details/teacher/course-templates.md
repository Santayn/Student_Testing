# Преподаватель: шаблоны курса

## 1. Открытие

Откройте раздел шаблонов курса и выберите нужный предмет.

## 2. Создание шаблона

1. Нажмите создание шаблона.
2. Введите название.
3. Настройте видимость/состояние, если соответствующий переключатель доступен.
4. Сохраните.

## 3. Изменение

Откройте шаблон, измените название или доступные параметры видимости и сохраните.

## 4. Удаление

Используйте действие удаления шаблона и подтвердите операцию, если требуется.

## 5. Переход к версиям

Откройте нужный шаблон, чтобы работать с его версиями. Версии позволяют хранить развитие учебного курса внутри одного шаблона.
