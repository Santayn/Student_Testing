# Преподаватель: материалы лекции

## 1. Добавление материалов

1. Откройте создание или редактирование лекции.
2. Перейдите к блоку материалов.
3. Выберите один или несколько файлов.
4. Проверьте список подготовленных к загрузке файлов.
5. Сохраните/загрузите изменения согласно интерфейсу.

До отправки лишний файл можно убрать из локального списка выбранных материалов.

## 2. Скачивание существующего файла

Откройте лекцию и используйте действие скачивания у нужного материала.

## 3. Удаление материала

В редакторе лекции найдите существующий файл и используйте действие удаления. При необходимости подтвердите операцию.

Удаление материала не равнозначно удалению самой лекции.
