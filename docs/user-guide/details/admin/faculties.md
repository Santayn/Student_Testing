# Администратор: факультеты

## 1. Создание

1. Откройте справочник факультетов.
2. Нажмите создание.
3. Введите название.
4. Укажите код.
5. Добавьте описание при необходимости.
6. Сохраните.

## 2. Редактирование

Откройте факультет, измените данные и сохраните.

## 3. Удаление

Используйте действие удаления и подтвердите операцию. Если факультет связан с другими данными, сервер может отклонить удаление до устранения зависимостей.

## 4. Поиск и сортировка

Используйте поиск и доступную сортировку для работы с большим справочником.
