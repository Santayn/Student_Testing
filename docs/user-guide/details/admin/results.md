# Администратор: результаты

Администратор может просматривать результаты в расширенном учебном контексте.

## 1. Открытие

Перейдите в раздел результатов в режиме администратора.

## 2. Последовательность фильтров

```text
Предмет → Лекция → Тест → Группа → Студент
```

Выберите столько уровней, сколько требуется для нужной детализации.

## 3. Просмотр данных

Доступны сведения о завершённых попытках, баллах, процентах и, при наличии соответствующего действия, подробностях ответов.

В отличие от студента, администратор не ограничен только собственными результатами. В отличие от преподавателя, его охват определяется административными правами, а не только собственной нагрузкой.
