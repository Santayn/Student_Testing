# Администратор: состав группы

## 1. Просмотр студентов

1. Откройте раздел групп.
2. Выберите нужную группу.
3. Перейдите к её составу.

## 2. Добавление студента

1. Найдите пользователя/студента среди доступных кандидатов.
2. Используйте действие добавления в группу.
3. Проверьте появление записи в активном составе.

## 3. Удаление из активного состава

Используйте действие удаления/исключения у конкретного студента. В текущей модели членство может сохраняться как неактивное, а не уничтожаться безвозвратно.

## 4. Возврат ранее исключённого студента

Найдите ранее исключённую запись и используйте действие восстановления членства.

Это позволяет сохранить историю связи пользователя с группой.
