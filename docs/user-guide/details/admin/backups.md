# Администратор: резервные копии

> **Внимание.** Восстановление базы данных является потенциально разрушительной операцией и может заменить текущие данные содержимым выбранной резервной копии. Перед восстановлением убедитесь, что выбран правильный файл.

## 1. Создание резервной копии

1. Переключитесь в режим администратора.
2. Откройте раздел резервных копий.
3. Используйте действие скачивания/создания резервной копии.
4. Дождитесь формирования файла.
5. Сохраните полученный SQL-файл в безопасном месте.

## 2. Восстановление

1. Откройте раздел резервных копий.
2. Выберите SQL-файл резервной копии.
3. Запустите восстановление.
4. Внимательно прочитайте предупреждение.
5. Подтвердите операцию только если файл и намерение верны.
6. Дождитесь сообщения о завершении.
7. Выполните перезагрузку приложения, если интерфейс предлагает или требует её после восстановления.

## 3. Перед восстановлением

Рекомендуется сначала создать актуальную резервную копию текущего состояния, чтобы сохранить возможность возврата.

Не используйте случайные или неизвестные SQL-файлы: восстановление предназначено для совместимых резервных копий Student Testing.
