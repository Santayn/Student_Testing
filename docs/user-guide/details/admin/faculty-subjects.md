# Администратор: предметы факультета

## 1. Выбор факультета

Откройте раздел связи факультетов и предметов и выберите нужный факультет.

## 2. Добавление предмета

1. Найдите предмет среди доступных.
2. Используйте действие добавления.
3. Проверьте, что он появился среди назначенных факультету.

## 3. Удаление связи

В списке назначенных предметов выберите нужную связь и используйте действие удаления/отвязки.

Удаление связи факультета с предметом не означает удаление самого предмета из общего справочника.
