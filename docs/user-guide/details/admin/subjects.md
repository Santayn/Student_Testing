# Администратор: предметы

## 1. Создание

1. Откройте справочник предметов.
2. Нажмите создание.
3. Заполните обязательные данные.
4. Сохраните.

## 2. Изменение

Откройте существующий предмет, измените поля и сохраните.

## 3. Удаление

Используйте действие удаления. Связанные факультеты, преподаватели, лекции и учебные назначения могут ограничивать удаление.

## 4. Поиск и сортировка

Используйте доступные элементы списка для быстрого поиска нужного предмета.
