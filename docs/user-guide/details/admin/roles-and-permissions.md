# Администратор: роли и права

## 1. Создание роли

1. Откройте раздел ролей и прав.
2. Создайте новую роль.
3. Укажите необходимые данные роли.
4. Сохраните.

## 2. Создание permission

В соответствующем разделе создайте новое разрешение и сохраните его.

## 3. Назначение прав роли

1. Откройте существующую роль.
2. Отметьте необходимые permissions.
3. Сохраните изменения.

## 4. Удаление права из роли

Снимите соответствующую отметку и сохраните набор разрешений.

## 5. Ограничения интерфейса

Текущая версия ориентирована на создание ролей/permissions и изменение состава прав роли. Полноценный пользовательский CRUD для самих существующих ролей и permissions ограничен.
