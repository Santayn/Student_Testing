# Администратор: персональный профиль пользователя

В системе учётная запись и персональный профиль являются разными сущностями.

```text
Учётная запись → авторизация и роли
Person → персональные сведения и рабочая привязка
```

## 1. Привязка существующего профиля

1. Откройте настройку пользователя.
2. Найдите блок персонального профиля.
3. Выберите существующий профиль, если он уже создан.
4. Сохраните связь.

## 2. Создание нового профиля

1. Откройте настройку пользователя.
2. Выберите создание персонального профиля.
3. Заполните доступные поля: фамилию, имя, дату рождения, email и телефон.
4. Сохраните.

## 3. Изменение профиля

Откройте связанный профиль, измените нужные данные и сохраните.

Наличие корректной связи с профилем важно для доступа пользователя к рабочим разделам системы.
