# Администратор: предметы преподавателя

## 1. Выбор преподавателя

Откройте раздел назначений преподавателей и выберите нужного преподавателя.

## 2. Назначение предмета

1. Найдите предмет среди доступных.
2. При необходимости добавьте примечание.
3. Создайте назначение.

## 3. Снятие назначения

Выберите предмет среди назначенных и используйте действие снятия/деактивации связи.

## 4. Повторное назначение

Если такая связь существовала ранее и была приостановлена, интерфейс может восстановить существующее назначение вместо создания полностью новой записи.

Именно эта связь определяет, с какими предметами преподаватель может работать в своём рабочем пространстве.
