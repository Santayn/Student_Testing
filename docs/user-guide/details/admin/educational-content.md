# Администратор: учебный контент

Администратор имеет доступ к части преподавательских рабочих пространств и может обслуживать существующий учебный контент.

## 1. Доступные разделы

В административном режиме доступны переходы к таким областям, как:

- темы;
- вопросы;
- лекции;
- шаблоны и версии курса;
- результаты.

Практика работы внутри этих разделов во многом совпадает с [руководством преподавателя](../teacher/README.md).

## 2. Отличие от преподавателя

Администратор работает с системой шире, но не обязан подменять преподавателя во всех сценариях. Некоторые действия намеренно ограничены.

В частности, создание нового шаблона курса относится к преподавательскому сценарию: администратор может работать с существующим содержимым, но новый шаблон должен создавать преподаватель.

## 3. Рекомендуемый подход

Используйте административное вмешательство для настройки, проверки или обслуживания данных. Повседневное авторское ведение учебного курса лучше выполнять из роли преподавателя.
