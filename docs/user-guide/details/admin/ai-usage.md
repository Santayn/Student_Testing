# Расход ИИ

Раздел «Система → Расход ИИ» показывает, сколько ИИ израсходовал за период (по умолчанию — текущий месяц):

- **итоги** — токены, число задач, распознанные страницы и расход месяца относительно лимита;
- **по задачам** — проверка ответов, подсказка критериев, распознавание сканов, план и сборка презентаций;
- **по преподавателям** — проверка ответов засчитывается автору теста, остальное — тому, кто запустил задачу;
- **по группам** — проверка ответов студентов каждой группы.

Преподаватели и студенты расход не видят. Чтобы открыть отчёт модератору, выдайте его роли право «View AI usage reports» (`ai.usage.read`) в разделе «Роли и права».
