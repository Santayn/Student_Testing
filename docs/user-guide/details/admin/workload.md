# Администратор: учебная нагрузка

## 1. Выбор учебного контекста

Перед созданием назначения задайте контекст, используемый в интерфейсе:

- факультет;
- курс;
- семестр;
- учебный год.

## 2. Создание нагрузки

1. Нажмите создание назначения.
2. Выберите предмет.
3. Выберите преподавателя.
4. Укажите тип нагрузки.
5. Укажите часы в неделю.
6. При необходимости выберите версию курса.
7. Выберите статус.
8. Выберите одну или несколько групп.
9. Проверьте курс, семестр и учебный год.
10. Добавьте примечание при необходимости.
11. Сохраните.

Если выбрано несколько групп, система создаёт соответствующие назначения для каждой группы.

## 3. Проверка дублей

Перед созданием система проверяет конфликтующие назначения в одном учебном контексте. Если уже существует нагрузка для сочетания предмета, группы и периода, исправьте параметры вместо создания дубликата.

## 4. Статусы

Используются состояния вроде:

- активно;
- черновик;
- закрыто;
- в паузе.

## 5. Изменение существующей нагрузки

Откройте назначение, измените доступные поля и сохраните. Для завершённых или временно неактивных назначений используйте изменение статуса.

## 6. Ограничение

Отдельная операция полного удаления нагрузки в текущем пользовательском интерфейсе не является основным сценарием; жизненный цикл управляется изменением данных и статуса.
