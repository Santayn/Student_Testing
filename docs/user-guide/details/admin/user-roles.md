# Администратор: роли пользователя

## 1. Назначение роли

1. Откройте список пользователей.
2. Перейдите к настройке нужного аккаунта.
3. Откройте блок ролей.
4. Отметьте необходимую роль.
5. Сохраните изменения.

## 2. Несколько ролей

Одному аккаунту можно назначить несколько ролей, например:

```text
STUDENT + TEACHER
```

или:

```text
TEACHER + ADMIN
```

После этого пользователь сможет переключать рабочий режим без отдельной учётной записи.

## 3. Снятие роли

Уберите ненужную роль и сохраните изменения. Перед снятием убедитесь, что пользователь не зависит от этой роли в текущем учебном процессе.

## 4. Просмотр permissions

В настройке аккаунта могут отображаться итоговые права пользователя. Изменение самих permission-наборов выполняется через управление ролями, а не напрямую на уровне конкретного пользователя.
