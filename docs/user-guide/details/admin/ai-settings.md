# Настройки ИИ

Раздел «Система → Настройки ИИ»: для каждой функции выбирается движок.

- **Внешний API** — модель провайдера из настроек сервера, тратит токены;
- **Собственная модель** — модель на самом сервере, без внешнего API и токенов.

Функции: проверка свободных ответов, подсказка критериев, скан лекции. Выбор действует сразу для всех преподавателей. Вариант недоступен, если он не настроен на сервере или его модель не загружена — состояние видно на карточке функции.

Собственная проверка ответов слабее внешнего API: уверенные оценки она ставит сама, а сомнительные ответы отправляет преподавателю в «Проверку ответов».

Раздел доступен администратору (право «Choose AI engines», `ai.settings.manage`).
