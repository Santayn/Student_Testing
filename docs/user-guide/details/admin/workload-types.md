# Администратор: типы нагрузки

Типы нагрузки используются при формировании учебных назначений, например для разделения лекционной, практической или лабораторной работы.

## 1. Создание

1. Откройте справочник типов нагрузки.
2. Нажмите создание.
3. Заполните данные типа.
4. Сохраните.

## 2. Редактирование

Откройте существующий тип, измените значения и сохраните.

## 3. Поиск

Используйте строку поиска или фильтры, если они доступны в текущем представлении.

## 4. Ограничение

Полное удаление типа нагрузки через текущий UI не является основным доступным сценарием.
