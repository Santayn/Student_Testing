# Администратор: пользователи

## 1. Открытие списка

Переключитесь в режим администратора и откройте раздел пользователей.

## 2. Поиск и фильтрация

Для поиска пользователя можно использовать доступные критерии, включая логин, ФИО, email, телефон, роль, активность и наличие персонального профиля.

## 3. Настройка пользователя

Откройте действие настройки у выбранной записи. Из этого сценария доступны операции с активностью аккаунта, персональным профилем и ролями.

## 4. Отключение аккаунта

Используйте переключение активности пользователя, если требуется временно запретить доступ без удаления самой записи.

## 5. Повторная активация

Ранее отключённый аккаунт можно снова активировать через те же настройки.
