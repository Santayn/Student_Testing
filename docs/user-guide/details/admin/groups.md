# Администратор: группы

## 1. Создание группы

1. Откройте раздел групп.
2. Нажмите создание.
3. Заполните данные группы.
4. Выберите факультет.
5. Сохраните.

## 2. Изменение

Откройте группу, исправьте данные и сохраните.

## 3. Удаление

Используйте действие удаления. Перед подтверждением учитывайте связанные учебные назначения и состав группы.

## 4. Фильтрация

Используйте доступные фильтры и поиск для нахождения нужной группы.

## 5. Состав группы

Откройте группу и перейдите к управлению студентами. Подробный сценарий описан в [разделе состава группы](./group-members.md).
