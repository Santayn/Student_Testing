# Студент: лекции и материалы

## 1. Открытие лекций

1. Откройте раздел **«Предметы»**.
2. Выберите нужный предмет.
3. Перейдите к его лекциям.
4. Выберите лекцию из списка.

Для лекции могут отображаться название, описание, сведения о курсе или версии курса, прикреплённые материалы и связанные тесты.

## 2. Скачивание материала

Если преподаватель прикрепил файл:

1. Откройте нужную лекцию.
2. Найдите блок материалов.
3. Выберите файл.
4. Используйте действие скачивания.

Если материалов нет, это не является ошибкой: конкретная лекция может быть создана без файлов.

## 3. Связанные тесты

В блоке тестов отображаются назначенные для лекции тесты и их состояние.

Возможные состояния:

- **Доступен** — можно начать новую попытку;
- **Можно продолжить** — имеется незавершённая попытка;
- **Попытки закончились** — разрешённое количество попыток исчерпано;
- **Недоступен** — тест закрыт, приостановлен либо находится вне периода доступности;
- **Проверка недоступна** — системе не удалось получить актуальное состояние;
- отсутствие корректного назначения — запуск теста невозможен.

Рядом с тестом также может отображаться информация об использованных и оставшихся попытках.

## 4. Правильный путь к тесту

Открывайте тест со страницы соответствующей лекции. Прямой переход по адресу теста без корректного назначения не является штатным сценарием и может быть отклонён интерфейсом.
