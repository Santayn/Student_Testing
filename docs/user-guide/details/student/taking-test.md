# Студент: прохождение теста

## 1. Начало новой попытки

1. Откройте предмет.
2. Перейдите к нужной лекции.
3. Найдите тест со статусом, позволяющим начало новой попытки.
4. Нажмите действие прохождения теста.
5. Дождитесь загрузки попытки и вопросов.

Система запускает попытку через назначение теста. Простое открытие страницы теста не должно само по себе расходовать попытку.

## 2. Типы вопросов

### Один вариант ответа

Выберите один вариант из предложенных. Выбор нового варианта заменяет предыдущий.

### Несколько вариантов ответа

Отметьте все варианты, которые считаете правильными. При необходимости отметку можно снять до завершения теста.

### Сопоставление

Установите соответствия между элементами двух наборов в доступном интерфейсе вопроса.

### Текстовый ответ

Введите ответ в текстовое поле.

## 3. Контроль прогресса

Во время прохождения система показывает количество отвеченных вопросов и число вопросов без ответа. Используйте этот индикатор перед завершением теста, чтобы проверить полноту заполнения.

## 4. Изменение ответов

До отправки попытки можно возвращаться к вопросам и изменять выбранные ответы. Промежуточные значения сохраняются как локальный черновик текущей попытки.

## 5. Завершение теста

1. Проверьте ответы.
2. Используйте действие завершения/отправки теста.
3. Если остались вопросы без ответа, система предупредит об этом.
4. Выберите: вернуться к вопросам или сознательно завершить тест с пропусками.
5. После подтверждения дождитесь результата отправки.

## 6. После успешной отправки

После успешного завершения отображается результат попытки: доступные сведения о правильности, балле и других показателях. Далее можно перейти к собственным результатам либо вернуться к учебному контексту лекции.

## 7. Ошибка сети при отправке

Если соединение оборвалось в момент завершения, не пытайтесь многократно отправлять попытку вручную, если интерфейс сообщает, что результат операции неизвестен. Сервер мог уже принять результат. Сначала обновите состояние через штатные страницы результатов или лекции.
