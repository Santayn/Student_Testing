# Студент: работа с предметами

## 1. Открытие списка предметов

1. Войдите в систему в режиме студента.
2. Откройте раздел **«Предметы»** через основную навигацию.
3. Дождитесь загрузки списка доступных предметов.

Студент видит только тот учебный контекст, который доступен ему через настройки системы и принадлежность к учебной группе.

## 2. Поиск предмета

Если список большой, используйте строку поиска и введите часть названия предмета. Очистите строку, чтобы снова показать полный доступный список.

## 3. Обновление списка

Если администратор или преподаватель только что изменил назначения, используйте действие обновления страницы или списка, чтобы загрузить актуальные данные.

## 4. Переход к предмету

Нажмите на нужный предмет. Откроется его рабочая страница с доступной информацией и переходом к лекциям.

Если нужного предмета нет, студент не может добавить его самостоятельно. Необходимо проверить состав группы и учебные назначения у администратора.
