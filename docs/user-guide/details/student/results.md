# Студент: просмотр результатов

## 1. Открытие результатов

1. Войдите в систему в режиме студента.
2. Откройте раздел **«Результаты»**.
3. Дождитесь загрузки доступных попыток.

Студенческий режим предназначен только для просмотра собственных результатов.

## 2. Фильтрация

В зависимости от доступных данных можно выбрать предмет и тест, чтобы сократить список результатов.

## 3. Что можно посмотреть

Для попыток могут отображаться:

- результат и количество баллов;
- процент выполнения;
- сведения о попытке;
- лучший достигнутый результат;
- подробности ответов, если они доступны в интерфейсе.

## 4. Если результатов нет

Проверьте, был ли тест действительно завершён и отправлен. Незавершённая попытка не является завершённым результатом.
