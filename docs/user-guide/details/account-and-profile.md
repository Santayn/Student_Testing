# Аккаунт и профиль

## 1. Открытие профиля

Откройте меню текущего пользователя и перейдите в профиль. На странице отображаются доступные сведения об учётной записи и связанном персональном профиле.

Если часть персональных данных отсутствует, их заполнение может требовать действий администратора.

## 2. Смена пароля

1. Откройте раздел профиля.
2. Перейдите к изменению пароля.
3. Введите текущий пароль.
4. Введите новый пароль.
5. Повторите новый пароль в поле подтверждения.
6. Сохраните изменения.

После успешной смены пароля текущая авторизованная сессия завершается. Выполните вход снова уже с новым паролем.

## 3. Тема интерфейса

В интерфейсе поддерживаются светлая и тёмная темы. Переключение темы изменяет оформление приложения, но не влияет на данные и текущую роль.

## 4. Переключение роли

Для аккаунтов с несколькими ролями доступно переключение рабочего режима.

Пример:

```text
TEACHER → ADMIN
```

После переключения меняются боковая навигация, главная страница и доступные рабочие разделы. Один и тот же аккаунт при этом остаётся авторизованным.
