# Начало работы

## 1. Вход в систему

1. Откройте Student Testing в браузере.
2. На странице входа введите логин и пароль.
3. Нажмите кнопку входа.
4. После успешной авторизации система загрузит сведения об аккаунте и перенаправит пользователя в доступное рабочее пространство.

Если данные введены неверно или сервер недоступен, интерфейс покажет сообщение об ошибке. Повторите вход после исправления причины.

## 2. Регистрация

Самостоятельная регистрация доступна только тогда, когда она включена в конфигурации приложения.

Если на странице входа присутствует переход к регистрации:

1. Откройте форму регистрации.
2. Заполните обязательные поля.
3. Отправьте форму.
4. После создания учётной записи выполните вход.

Наличие учётной записи ещё не гарантирует доступ к рабочим разделам: для ряда сценариев аккаунт должен быть связан с персональным профилем и иметь рабочую роль.

## 3. Страница ожидания настройки аккаунта

Если пользователь успешно вошёл, но его рабочий профиль ещё не подготовлен, система может открыть страницу ожидания настройки аккаунта.

Обычно это означает одно из следующих состояний:

- аккаунту ещё не назначена рабочая роль;
- аккаунт не связан с профилем пользователя;
- административная настройка ещё не завершена.

После того как администратор внесёт изменения, используйте действие повторной проверки доступа на этой странице. Повторная регистрация для этого не требуется.

## 4. Выбор рабочего режима

Если аккаунт имеет только одну рабочую роль, система открывает соответствующее пространство автоматически.

Если пользователю назначено несколько ролей, например `TEACHER` и `ADMIN`, рабочий режим можно переключать через элементы верхней панели приложения. Смена режима изменяет доступную навигацию и набор страниц, но не требует повторного входа.

## 5. Выход

Для завершения работы используйте действие выхода из аккаунта в интерфейсе пользователя. После выхода защищённые разделы становятся недоступны до следующей авторизации.
