# Руководство пользователя Student Testing

Этот раздел содержит практические инструкции по работе с системой Student Testing. Материалы сгруппированы по пользовательским задачам и ролям.

## [Начало работы](./details/getting-started.md)

Вход, регистрация, восстановление рабочей сессии, страница ожидания настройки аккаунта и выход из системы.

## [Аккаунт и профиль](./details/account-and-profile.md)

Профиль пользователя, смена пароля, тема интерфейса и переключение рабочего режима для многоролевых учётных записей.

## [Руководство студента](./details/student/README.md)

Работа с предметами и лекциями, прохождение тестов, продолжение незавершённых попыток и просмотр собственных результатов.

## [Руководство преподавателя](./details/teacher/README.md)

Темы, банк вопросов, импорт, тесты, лекции, материалы, шаблоны и версии курса, учебная нагрузка и результаты студентов.

## [Руководство администратора](./details/admin/README.md)

Пользователи, роли, факультеты, группы, предметы, назначения, учебная нагрузка, результаты, учебный контент и резервные копии.
