# Остановка и сброс среды

## Остановка контейнеров

Без удаления containers:

```bash
docker compose stop
```

Повторный запуск:

```bash
docker compose start
```

## Удаление containers с сохранением данных

```bash
docker compose down
```

Удаляются containers и Compose network, но named volumes остаются.

После этого:

```bash
docker compose up -d
```

поднимет приложение с прежней БД и файлами материалов.

## Полный сброс локальных данных

```bash
docker compose down -v
```

удалит:

```text
postgres-data
lecture-uploads
```

Следующий запуск будет рассматриваться как новая среда.

> Перед `down -v` убедитесь, что данные действительно больше не нужны. Восстановление возможно только из заранее подготовленных backup.

## Удаление images

Обычный `down` не обязательно удаляет собранные images. Их можно удалить отдельными Docker-командами, если требуется полностью очистить локальный cache/build.

## `.env`

`docker compose down` не удаляет локальный `.env`.

Если требуется создать новые секреты через `start-local.ps1`, старый файл нужно удалить или сделать его невалидным; скрипт при замене сохранит backup.
