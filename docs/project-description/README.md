# Описание проекта Student Testing

Student Testing — клиент-серверная информационная система для организации учебного процесса, подготовки учебного контента, проведения тестирования и анализа результатов. Система разделяет рабочие возможности между тремя основными ролями: **студентом**, **преподавателем** и **администратором**.

Этот раздел описывает **что представляет собой система и какие задачи она решает**. Пошаговые инструкции по работе с интерфейсом будут вынесены в отдельное руководство пользователя.

## [Общее описание системы](./details/general-description.md)

Назначение проекта, основные задачи, состав функциональных областей и место каждой роли в общем процессе работы.

## [Роли и разграничение возможностей](./details/roles-and-permissions.md)

Описание ролей `STUDENT`, `TEACHER` и `ADMIN`, многоролевых учётных записей, рабочего режима пользователя и общих условий доступа к разделам системы.

## [Возможности студента](./details/student-features.md)

Работа с предметами, лекциями и материалами, прохождение назначенных тестов, сохранение ответов и просмотр результатов обучения.

## [Возможности преподавателя](./details/teacher-features.md)

Управление темами, банком вопросов, тестами, лекциями, учебными материалами, шаблонами курса, собственной нагрузкой и результатами студентов.

## [Возможности администратора](./details/admin-features.md)

Управление пользователями, ролями, академической структурой, назначениями преподавателей, учебной нагрузкой, учебным контентом и резервными копиями.

## [Организация учебного процесса](./details/educational-process.md)

Связи между пользователями, предметами, группами, преподавателями, лекциями, тестами и результатами; последовательность формирования учебного процесса в системе.

## [Текущие ограничения](./details/limitations.md)

Функциональные ограничения и особенности текущей реализации, которые важно учитывать при эксплуатации и дальнейшем развитии проекта.
