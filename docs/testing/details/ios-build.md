# Сборка и проверка на iPhone (Mac + симулятор)

Инструкция для тестера с Mac. Код iOS-версии общий с Android (Kotlin Multiplatform), отдельно собирается только Xcode-обёртка `mobile/iosApp`.

## Что нужно

- macOS на Apple Silicon (M1 и новее) — симулятор собирается под `iosSimulatorArm64`.
- Xcode 16 или новее, в нём установлен симулятор iOS (Xcode → Settings → Components → iOS).
- JDK 21: `brew install openjdk@21`, затем в `~/.zshrc`:
  `export JAVA_HOME=$(/usr/libexec/java_home -v 21)`.
- Android SDK — Gradle-проект общий, без него не настраивается даже iOS-сборка. Проще всего поставить Android Studio
  (SDK Platform 37 из SDK Manager) или только command-line tools. Путь к SDK — в `mobile/local.properties`:
  `sdk.dir=/Users/<имя>/Library/Android/sdk` (файл не в git, у каждого свой).
- Бэкенд: либо свой стек в Docker на этом же Mac (`docker compose up -d` в корне репозитория), либо стенд на другом компьютере в той же Wi-Fi-сети.

## Сборка и запуск в симуляторе

1. `git clone https://github.com/Santayn/Student_Testing.git`, нужная ветка — `git checkout feature/local-ai` (или `master` после слияния).
2. Первый раз проверить сборку общего кода из терминала (скачает зависимости, 5–15 минут):

   ```bash
   cd mobile
   ./gradlew :shared:compileKotlinIosSimulatorArm64
   ```

3. Открыть `mobile/iosApp/iosApp.xcodeproj` в Xcode.
4. Вверху выбрать схему `iosApp` и симулятор, например iPhone 16.
5. Run (⌘R). На шаге «Compile Kotlin Framework» Xcode сам вызывает Gradle (`embedAndSignAppleFrameworkForXcode`) — первая сборка долгая, дальше быстрее.

Для симулятора Team ID не нужен. Для установки на настоящий iPhone — указать свой Team ID в `mobile/iosApp/Configuration/Config.xcconfig` (`TEAM_ID=`), выбрать iPhone как устройство, при первом запуске на телефоне разрешить разработчика: Настройки → Основные → VPN и управление устройством. Изменение `Config.xcconfig` не коммитить.

## Адрес сервера

- Бэкенд в Docker на этом же Mac — ничего менять не нужно: симулятор ходит на `http://localhost:8080/api/v1`.
- Бэкенд на другом компьютере — на экране входа нажать иконку сервера справа вверху и ввести IP того компьютера, например `192.168.31.179`. Запросы пойдут через nginx фронтенда (порт 80). На компьютере со стендом должен быть открыт входящий порт 80.

Учётные записи — как в вебе (сид-аккаунты стенда или выданные руководителем).

## Особенности симулятора

- **Русский ввод:** в симуляторе I/O → Keyboard → Connect Hardware Keyboard, на Mac включить русскую раскладку — печатать с клавиатуры Mac.
- **Скан лекции:** камеры в симуляторе нет, кнопки «Сканировать» на iOS нет (системный сканер документов — только Android). Фото страниц перетащить мышью из Finder на окно симулятора — они попадут в «Фото». Кнопка «Файлы» открывает приложение «Файлы», поэтому в «Фото» выделить снимки → «Поделиться» → «Сохранить в Файлы». Затем в редакторе лекции «Распознать скан» → «Файлы» → выбрать их. Тестовые страницы есть в репозитории: `e2e/local-ai/fixtures/scan_p1.jpg`, `scan_p2.jpg`.
- **Озвучивание:** «Прочитать вслух» работает в симуляторе со звуком Mac; VoiceOver проверять лучше на настоящем iPhone.
- **Без сети:** выключить Wi-Fi на Mac — приложение показывает сохранённые экраны и сообщает об отсутствии связи.

## Что проверить

Тот же список, что для Android: [тест-кейсы ИИ](ai-test-cases.md) (разделы 1–8 и 7б — собственные модели), раздел «8. Мобильное приложение». Отдельно для iOS:

| № | Шаги | Ожидаемый результат |
|---|---|---|
| i.1 | Запуск, вход, выход, повторный вход после перезапуска | Сессия сохраняется (Keychain), выход очищает её |
| i.2 | Три темы оформления (Профиль → тема), светлая/тёмная, «Размер текста» | Без обрезанных текстов и наложений, кнопки в карточках не слипаются |
| i.3 | Студент сдаёт тест со свободными ответами (своя модель проверки включена) | После сдачи анимация «ИИ проверяет свободные ответы», затем статусы обновляются сами; на проверке — «У преподавателя» без баллов |
| i.4 | Преподаватель: «Предложить критерии» в вопросе «Свободный ответ» | Критерии появляются, сумма баллов = баллам вопроса |
| i.5 | Преподаватель: «Распознать скан» → «Файлы» → 2 фото → «Распознать» | Размеченный текст, «Вставить в текст лекции» работает |
| i.6 | Поворот экрана во время теста | Ответы и номер вопроса сохраняются |
| i.7 | Свернуть приложение посреди теста и вернуться | Ответы на месте («Ответы сохраняются на телефоне») |
| i.8 | Скачать материал лекции и открыть | Файл открывается, повторно — без интернета |

Найденное оформляйте как в отчёте тестера: шаги, ожидаемое, фактическое, скриншот (⌘S в симуляторе), версия iOS и модель симулятора.

## Если не собирается

- `SDK location not found` — нет `sdk.dir` в `mobile/local.properties`.
- `Unsupported class file major version` / ошибки Gradle про JDK — `JAVA_HOME` не на JDK 21 (`java -version`).
- Xcode: `Command PhaseScriptExecution failed` на «Compile Kotlin Framework» — открыть лог шага: обычно это та же ошибка Gradle; повторить в терминале `./gradlew :shared:embedAndSignAppleFrameworkForXcode` не получится без переменных Xcode, поэтому проверять командой из шага 2.
- Сборка падает с `Storage … is already registered` — в `mobile/gradle.properties` должно быть `kotlin.incremental=false` (уже включено); помогает `./gradlew --stop`.
- Симулятор не видит сервер на другом компьютере — проверить адрес на экране входа и что веб `http://<IP>` открывается в Safari на Mac.
