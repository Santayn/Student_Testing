# Оценивание текстовых ответов

## Правила

`DefaultTextAnswerEvaluationService` (интерфейс `TextAnswerEvaluationService`) использует `TextAnswerEvaluator`: нормализует ответ и сравнивает его с допустимыми вариантами (разделитель — `|` или перенос строки). Результат — `CORRECT`, `PARTIALLY_CORRECT` или `INCORRECT`. Проверка предсказуемая и не требует внешнего сервиса.

## Проверка по смыслу

Ответ, не совпавший с эталоном дословно, сначала получает предварительные баллы по правилам, а затем — если ИИ включён — проверяется моделью в фоне. Неуверенные и подозрительные оценки попадают преподавателю в очередь «Проверка ответов». Подробно: [ИИ](./ai.md).

Без ИИ ответ, засчитанный «по похожести», тоже попадает в очередь — его баллы подтверждает преподаватель.

## Источник истины

Окончательные баллы фиксирует backend; после поздней оценки (ИИ или преподавателем) итоговый балл попытки пересчитывается. Frontend не принимает решение о правильности ответа.

Прежний `LocalLlmTextAnswerEvaluationService` (синхронный вызов Ollama при сдаче, переменные `APP_TEXT_ANSWER_LOCAL_LLM_*`) удалён: локальную Ollama подключают как провайдер `openai`.
