# Техническая документация Student Testing

Этот раздел описывает **внутреннее устройство системы Student Testing**: архитектуру клиентской и серверной частей, модель данных, механизмы аутентификации и авторизации, ключевые предметные области, жизненный цикл тестирования, хранение файлов, обработку ошибок и эксплуатационные механизмы приложения.

Раздел не дублирует пошаговые инструкции пользователя, полный каталог REST endpoint'ов или команды развёртывания. Они выносятся соответственно в `user-guide`, `api` и `deployment`.

### [Архитектура backend](./details/backend-architecture.md)

Слои Spring Boot приложения, контроллеры, сервисы, репозитории, DTO, security и принципы выполнения бизнес-операций.

Структура Vue SPA, разделение `views`, `components`, `composables`, `api`, `stores`, маршрутизации и внутреннего UI-слоя.
