# Статусы и числовые коды

Одно и то же число **не имеет глобального значения** во всех сущностях. Всегда учитывайте тип объекта.

## Membership status

Для `FacultyMembership`, `GroupMembership`, `SubjectMembership`:

| Код | Значение |
|---:|---|
| `1` | Активно |
| `2` | Приостановлено |
| `3` | Удалено/завершено; устанавливается `removedAtUtc` |

## TestAssignment status

| Код | Значение |
|---:|---|
| `1` | Черновик |
| `2` | Активно |
| `3` | Закрыто |
| `4` | Приостановлено |

Студент может нормально начать попытку только при активном назначении и выполнении временных условий.

## TeachingAssignment status

| Код | Значение |
|---:|---|
| `1` | Активно |
| `2` | Черновик |
| `3` | Закрыто |
| `4` | В паузе |

Обратите внимание: `status=1` здесь означает **Активно**, тогда как у `TestAssignment` это **Черновик**.

## TestAttempt status

| Код | Значение |
|---:|---|
| `1` | Активная/незавершённая попытка |
| `2` | Завершённая попытка |

## TeachingAssignmentEnrollment status

Backend допускает диапазон `1..4`. В текущей логике `1` и `2` рассматриваются как текущие/активные состояния, а `3` и `4` приводят к установке `removedAtUtc`. Канонические человекочитаемые названия всех четырёх значений в коде не закреплены.

## LectureAssignment status

Допустимый диапазон — `1..4`. Для `status=3` используется `closedAtUtc`, но единый справочник названий всех четырёх значений отсутствует.

## StudentLectureProgress status

Допустимый диапазон — `1..3`.

- `1` используется как начальное/не завершённое состояние;
- `2` автоматически выбирается при достижении `minProgressPercent`;
- значение `3` API принимает, но его семантическая подпись не формализована в одном каноническом месте.

## completionSource

`StudentLectureProgress.completionSource` допускает `1..3`, по умолчанию `1`. Человекочитаемая семантика этих кодов в текущем исходном коде не закреплена.

## Boolean-состояния

| Поле | Смысл `true` |
|---|---|
| `User.active` | Учётная запись активна. |
| `Question.active` | Вопрос активен/доступен. |
| `CourseTemplate.publicVisible` | Шаблон видим. |
| `CourseVersion.published` | Версия опубликована. |
| `Lecture.publicVisible` | Лекция опубликована. |
| `QuestionOption.correct` | Вариант правильный. |
| `LectureAssignment.required` | Лекция обязательна. |

Неопределённые/контекстные коды перечислены также в [reference caveats](./reference-caveats.md).
