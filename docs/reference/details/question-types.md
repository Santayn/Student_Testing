# Типы вопросов

| Код | Тип | Ответ студента |
|---:|---|---|
| `1` | Один вариант ответа | Один выбранный option. |
| `2` | Несколько вариантов ответа | Набор выбранных options. |
| `3` | Сопоставление | Пары matching prompt ↔ option. |
| `4` | Текстовый ответ | Произвольный текст. |

## Оценка текстового ответа

Сервис оценки использует коэффициент результата:

| Результат | `scoreRatio` | `correct` |
|---|---:|:---:|
| Correct | `1.0` | `true` |
| Partially correct | `0.5` | `false` |
| Incorrect | `0.0` | `false` |

Поэтому `correct=false` не обязательно означает нулевой балл: частично правильный текстовый ответ может получить половину баллов.

## Безопасность student DTO

Student-facing API не должен отдавать признаки правильности вариантов или `correctAnswer` до/во время прохождения теста. Подробнее: [Student Learning API](../../api/details/student-learning.md).
