This file is the working completion register for the backend audit and recommendation list. It records which items are already implemented in the backend, how they were implemented, and what remains open.

Status meanings:

- DONE: backend implementation exists and a targeted regression/contract test was found, or the item is configuration-only and the relevant config is in place.
- PARTIAL: part of the requested backend behavior exists, but a meaningful contract, safety, data, or test gap remains.
- OPEN: no sufficient backend implementation was found during this review.
- DECISION: the item depends on a product/business decision before engineering work should continue.
- NOT_REQUIRED: the recommendation was explicitly reviewed and closed because the current product contract intentionally does not include that capability.

Do not mark an item DONE because the frontend works around it. Mark DONE only when the backend itself enforces the rule or provides the contract.
