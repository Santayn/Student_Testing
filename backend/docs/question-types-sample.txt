ОБРАЗЕЦ ЗАПОЛНЕНИЯ ВОПРОСОВ

По текущему DOCX-импорту вопросы разделяются пустой строкой.
Можно писать "Вопрос 1:", "1.", "Question 1:" или просто номер.
Баллы можно указывать строкой "Баллы: 1" или "Points: 1".

Важно: текущий QuestionDocxImportParser импортирует из DOCX вопросы с одним вариантом,
с несколькими вариантами и текстовый ответ. Тип "сопоставление" в DOCX-импорте сейчас
не разбирается отдельным типом, поэтому для него ниже дан формат заполнения для формы/API/DataLoader.


1. ВОПРОС С ОДНИМ ПРАВИЛЬНЫМ ВАРИАНТОМ

Вопрос 1: Какой язык используется для разработки Spring Boot-приложений?
Баллы: 1
A) Python
B) Java
C) HTML
D) SQL
Ответ: B

То же самое можно отметить звездочкой или плюсом:

Вопрос 2: Какой оператор SQL используется для выборки данных?
Баллы: 1
A) INSERT
*B) SELECT
C) DELETE
D) UPDATE


2. ВОПРОС С НЕСКОЛЬКИМИ ПРАВИЛЬНЫМИ ВАРИАНТАМИ

Вопрос 3: Какие элементы относятся к реляционной базе данных?
Баллы: 2
A) Таблица
B) Столбец
C) CSS-класс
D) Первичный ключ
Ответ: A, B, D

То же самое можно отметить прямо в вариантах:

Вопрос 4: Какие утверждения про тестирование верны?
Баллы: 2
*A) Тест может содержать несколько вопросов
*B) Вопрос может иметь баллы
C) Правильный ответ всегда один
D) Все ответы всегда засчитываются автоматически


3. ВОПРОС НА СОПОСТАВЛЕНИЕ

Для формы/API/DataLoader:

Тип: 3
Вопрос: Соотнесите термин с описанием.
Баллы: 1
Пары сопоставления:
1. Лекция -> Учебный материал
2. Тема -> Раздел лекции
3. Тест -> Проверка знаний

Пример для DataLoader:

QuestionTypeSupport.TYPE_MATCHING
questionText: "Соотнесите термин с описанием."
matchingPairs:
new QuestionTypeSupport.MatchingPair(1, "Лекция", "Учебный материал")
new QuestionTypeSupport.MatchingPair(2, "Тема", "Раздел лекции")
new QuestionTypeSupport.MatchingPair(3, "Тест", "Проверка знаний")

Пример JSON для REST-запроса:

{
  "type": 3,
  "question": "Соотнесите термин с описанием.",
  "points": 1,
  "ordinal": 1,
  "matchingPairs": [
    { "ordinal": 1, "left": "Лекция", "right": "Учебный материал" },
    { "ordinal": 2, "left": "Тема", "right": "Раздел лекции" },
    { "ordinal": 3, "left": "Тест", "right": "Проверка знаний" }
  ]
}


4. РАЗВЕРНУТЫЙ / ТЕКСТОВЫЙ ОТВЕТ

Вопрос 5: Что означает аббревиатура CPU?
Баллы: 1
Ответ: Central Processing Unit

Если допустимо несколько правильных текстовых вариантов, их можно разделить символом "|":

Вопрос 6: Назовите команду SQL для выборки строк из таблицы.
Баллы: 1
Ответ: SELECT | select | Select


КРАТКИЕ ПРАВИЛА

1. Между вопросами оставляйте пустую строку.
2. Для вариантов можно использовать A), B), C), 1), 2) или маркированный список.
3. Правильные варианты можно указывать строкой "Ответ: A, C" или отмечать символом "*" перед вариантом.
4. Если у вопроса нет вариантов, DOCX-импорт считает его текстовым вопросом.
5. Для сопоставления нужно минимум две пары, левая и правая части не должны повторяться.
